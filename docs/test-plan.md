# In-sim test plan

Checks that need a running sim. Unit tests (`dotnet test plugin/TurnTelemetry.slnx`) cover the logic. These cover what only SimHub and the sims can confirm. Record results and any surprises in the Notes column.

## Phase 1: plugin core

**Setup:**

1. Close SimHub, then build and deploy: `dotnet build plugin/TurnTelemetry/TurnTelemetry.csproj -c Release -p:Deploy=true`.
2. Start SimHub and accept the prompt to enable **Turn Telemetry**.
3. Open the plugin's tab in the left menu. Its **Live diagnostics** section is used throughout.
